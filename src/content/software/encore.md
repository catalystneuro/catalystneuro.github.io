name: "Encore Science"
description: "Our first project in agentic science, where AI agents carry out scientific work end to end rather than assisting a person with one step of it. Encore Science is a public registry of attempts to reproduce the key findings of published papers from their open data, with agents doing the work. An agent reads each paper and writes its claims down before running any analysis, then tries to reproduce them from the dataset the paper deposited, starting with the DANDI Archive. Independent agents check every attempt, and each claim gets a recorded outcome whether or not it reproduced, along with an executed notebook and any problems found in the data itself. A failure to reproduce may be a failure of the agent and is not a judgement of the paper. The same checks can be run on a lab's own data with the encore command."
